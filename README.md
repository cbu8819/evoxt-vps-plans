## 官网写的「最高 6.0 GHz」，实际能拿到多少

「最高 6.0 GHz」指的是加速频率的上限，不是所有核心一直跑在这个频率上。这个数字对单核敏感的任务有意义：PHP 单请求处理、MySQL 单条复杂查询、代码编译，以及 Windows 远程桌面里的窗口响应。这类任务里，CPU 频率是唯一影响执行速度的因素，核心数再多也帮不上忙。

实际表现可以参考公开的第三方跑分。聚合站收录了 4 份 Evoxt 的 YABS 测试记录，覆盖 VM-1、VM-2、VM-4、VM-8 四档，Geekbench 6 单核成绩落在 1964 到 2722 之间，多核从 2385 到 11459。这些记录里识别出的 CPU 是 AMD EPYC（Genoa 与 Milan 两代），每档只跑了一次，只能当作参考区间，不能当成性能承诺。不过它至少说明一件事：这批机器用的是 EPYC 平台，而不是清库存的老至强。

磁盘方面更值得关注。同 4 份记录里，顺序读取速度在 1.38 GB/s 到 2.14 GB/s 之间。SATA SSD 的理论带宽上限是 600MB/s，NVMe 走 PCIe 通道，单盘顺序读写能到 3GB/s 以上，IOPS 相差数倍。有第三方 benchmark 统计，在并发小文件读写场景下，NVMe VPS 的吞吐比同档 SATA SSD VPS 高 300%–600%。换到具体使用上，拉 Docker 镜像、跑 MySQL、装 WordPress 插件、解压几百 MB 的压缩包，差距体现在等待时间上：用 SATA 的机器会让你盯着进度条，用 NVMe 的机器你可能还没切到浏览器，它就已经跑完了。Evoxt 全系使用 NVMe，这一点在 $2.99 的入门档上也没有缩水。
